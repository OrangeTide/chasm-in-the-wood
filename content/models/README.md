# Models

Free-standing voxel models: the player, the monsters, and the loot props. Each is a
`.vox` file loaded at startup, with a generated placeholder (a ball, see
`src/render/prims.pas`) standing in when the file is absent. So authored art drops in one
file at a time; a monster or item with no file stays a placeholder ball until its file
lands.

## Files

```
content/models/player.vox        the player character
content/models/<monster-id>.vox  a monster, by its lower-cased content id
content/models/<item-id>.vox     a loot prop, by its lower-cased content id
```

- `player.vox` is the player. When absent the player is a ball.
- A monster model is named by the monster's id from `content/monsters.txt`, lower-cased:
  `rat.vox`, `orc.vox`, `demon.vox`, and so on.
- A loot model is named by the item's id from `content/items.txt`, lower-cased:
  `sword.vox`, `potion.vox`, `torch.vox`, and so on.

Every file is optional. A monster or item with no model draws the placeholder ball,
tinted as before; the others draw their authored model untinted.

The objective draws the relic model (`relic.vox`) and a locked chest draws `chest.vox`,
a model not keyed to an item id (the chest hides its reward). Not drawn from a model yet:
townsfolk (still placeholder balls), the quest interaction points, and the four armour
items, which keep their own-coloured placeholders.

## Conventions

- **Format**: a `.vox` file (MagicaVoxel / VoxelAI export), read by `voxfile.pas`. The
  model carries its own palette, so it draws in its own colours.
- **Scale**: a model is placed at the object voxel-unit (`VU` in the program), so its size
  is its voxel count: a monster of about `TILE_FOOT` = 16 voxels fills roughly one tile.
  Size the art in voxels to the bulk you want on screen; the placeholder balls range from
  8 to 33 voxels across, smallest to largest.
- **Footing**: the model is seated with its feet on the floor and centred on its tile, the
  same as the player, so author it standing upright in the file's z-up.
