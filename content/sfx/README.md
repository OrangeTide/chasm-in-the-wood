# Sound effects

The game fires a one-shot sound at the actions that carry the loop. Each is an OGG
Vorbis file loaded from this directory when present, and silent when absent, so effects
drop in one file at a time. Playback is through the audio unit (`src/game/audio.pas`),
mixed over the music through a small pool of voices, so a few effects overlap before the
oldest is cut. Gameplay fires them by name through `src/game/sfx.pas`, which stays silent
until the main program wires the audio backend.

## Files

```
content/sfx/<name>.ogg
```

| File | Plays when |
| --- | --- |
| `swing.ogg` | The player swings at a foe in reach. |
| `hit.ogg` | A player swing lands. |
| `hurt.ogg` | A monster's blow lands on the player. |
| `pickup.ogg` | Loot is taken, or a chest or locked door is opened. |
| `stairs.ogg` | The player takes a stair between depths or to town. |
| `menu.ogg` | A front-end menu button is clicked. |

Every file is optional. A missing one leaves that action silent; the others still play.

## Conventions

- **Format**: OGG Vorbis, decoded by the vendored stb_vorbis. Any channel count and
  sample rate work; the device resamples and mixes.
- **Length**: keep effects short, well under a second, so they do not pile up in the voice
  pool. A clip is pushed whole into one voice and drained once, not looped.
- **Level**: master the clips at a consistent level. The effects share one volume, set
  near full by default and separate from the music volume.
