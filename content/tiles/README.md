# Authored tiles

The world is drawn from one mesh per tile kind, per environment. Each is an authored
voxel model loaded from this directory when present, and a generated placeholder (see
`src/render/prims.pas`) when absent. So authored art drops in one file at a time; a
kind with no file stays procedural until its file lands. The loader is `TileKitLoad`
in `src/render/tilekit.pas`.

## Layout

```
content/tiles/<env>/<kind>.vox
```

- `<env>` is one of `dungeon`, `forest`, `town`.
- `<kind>` is one of `floor`, `wall`, `door`, `doorleaf`, `stairup`, `stairdn`.

Every combination is optional. For example, `content/tiles/dungeon/floor.vox` replaces
the generated dungeon floor, while a missing `content/tiles/forest/door.vox` leaves the
forest door as the generated arch.

| Kind | What it is | Placeholder |
| --- | --- | --- |
| `floor` | The walkable ground plate. | A plate one tile tall. |
| `wall` | The solid wall block. | A taller plate. |
| `door` | An open, walkable doorway. | An arch. |
| `doorleaf` | A shut (locked) door that bars the way until a key opens it. | A plate filling the frame. |
| `stairup` | Steps climbing toward the level above. | A short flight of steps. |
| `stairdn` | Steps descending toward the level below. | The same flight, reversed by the drawer. |

## Conventions

- **Format**: a `.vox` file (MagicaVoxel / VoxelAI export), read by `voxfile.pas`. The
  file is z-up (height along the file's z); the loader bakes it into the engine's y-up.
- **Footprint**: a tile fills one world cell of `TILE_FOOT` = 16 voxels square. Author a
  tile to that footprint so it scales to the cell the same way the free-standing models
  do. Wider or taller art is clamped to `TILE_GRID` = 50 across and `TILE_MAXH` = 64 tall.
- **Heights**: the generated wall and door stand `TILE_WALLH` = 40 voxels tall and the
  stairs `TILE_STEPH` = 30; match those if a tile should line up with its neighbours.
- **Stairs**: the steps run along the tile's +x axis; the drawer reverses them for the
  down variant, so one model can serve both if symmetric.
